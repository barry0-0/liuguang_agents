# Homepage demo video

`liuguang-demo.mp4` is the homepage's sanitized brand demo. It is a four-second static Liuguang brand animation encoded as H.264 in an MP4 container at 1920 × 1080 and 24 fps. `liuguang-demo.jpg` is its poster. Both assets use the Liuguang stream mark and the same sanitized sample labels; neither contains a real session, terminal transcript, or live SSH connection.

## Sample labels

- `liuguang-demo`: sample local project.
- `cli-sessions`: sample agent sessions.
- `web-app`: sample test host.
- `test-host`: placeholder SSH host.

The website build copies all `.jpg` and `.mp4` files from this directory into the published assets directory. Replace both files together and update the page references when either changes.

## Chapters

The chapter buttons in `index.html` jump to points that described the original narrated demo. The current sanitized brand video is intentionally short and does not contain chapters. Keep the current page references until a new full demo replaces both the video and its chapters.
